# ADR-0002: 积分即日元现金(1 积分 = 1 日元)

- 日期:2026-08-25
- 状态:已接受

## 背景

积分模块的「积分名称、积分规则、变更与兑换/抵扣/延迟到账」需求中,用户明确:积分是日元现金等价物,不是虚拟点数。

## 决策

- 积分单位与日元固定挂钩,**默认 1 积分 = 1 日元**(汇率可在系统配置中调整)。
- 积分账户属于 **AA 参与人**(Person 即积分持有者),非独立主体。
- 获取方式为**消费获得**(消费返积分),非充值;一笔积分拆分为「立即到账 + 延迟到账(T+N)」,延迟部分到期日入账。
- 使用方式:抵扣消费、转账给其他参与人、手动调整。

## 权衡

| 备选 | 放弃原因 |
|---|---|
| 虚拟积分(不可兑现) | 与「积分=现金」的业务事实不符 |
| 独立积分账户体系 | 徒增实体;参与人即持有者最简 |

## 后果

- 积分余额即现金权益,界面需展示「可用 + 待入账」两态与延迟到账日历。
- 金额字段统一以整数「分/日元」或小数日元存储,避免浮点误差(实现细节)。
